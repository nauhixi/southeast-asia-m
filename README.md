
# ICN-CXR Route Intelligence Dashboard

인천(ICN) ↔ 나트랑(CXR) 노선의 항공 및 여행시장 동향 대시보드입니다.

## 기능
- 평균 운임 추이 그래프
- 항공사 공급 비중
- 여행시장 코멘트
- GitHub Actions 자동 업데이트
- 반응형 디자인

## GitHub 업로드 방법
1. 새 Repository 생성
2. Add file → Upload files
3. ZIP 압축 해제 후 전체 업로드
4. Settings → Pages → Deploy from branch → main 선택

## 자동 업데이트
GitHub Actions가 매일 오전 8시(KST)에 실행됩니다.
